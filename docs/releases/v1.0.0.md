# Firefly Grove 1.0.0

First stable release of the animated TV screensaver.

## Included

- Procedural, continuously animated fireflies with slowly drifting paths, soft bloom, and pulsing glow.
- Woodland, meadow, and riverbank habitat choices.
- Five density levels, three flight speeds, three glow colors, individual random settings, and a randomize-all option.
- DreamService, remote-friendly settings, app preview, and a documented settings-provider contract.
- Guided install, update, and uninstall CLI with release checksum verification.

## Upgrade

Install or update with `python3 install.py --serial TV_IP:5555`. Existing device settings and screensaver selection are not changed. For manual installation, download the APK and checksum from this release and verify with:

```bash
shasum -a 256 -c firefly-grove.apk.sha256
```

This is the initial release; there are no breaking changes or migration steps.
